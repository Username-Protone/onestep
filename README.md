# OneStep - タスク管理アプリ

> 「今やる1歩」に集中するシンプルなタスク管理ツール

行動開始時の判断コストを下げ、ユーザーが反射的に次の行動へ移れる状態を作ることを目的としています。

---

## 🎯 コンセプト

- **情報量を最小化** → 次の1サブタスクだけを表示
- **判断コスト削減** → 「今何をすべきか」を即座に提示
- **シンプルなUX** → 機能を増やさず、動作を速く

---

## ✅ 実装済み機能

### ホーム画面 (`#home`)
- 締切が最も近い未完了サブタスクを **1件だけ** 表示
- 表示内容: サブタスク名 / 着手日 / 締切日 / 残り日数
- リンクのチップ表示
- **完了ボタン** で次のサブタスクへ自動切替
- **サブタスクを分割ボタン** で、その場でさらに小さな作業へ再設計可能
- 全タスク完了時の空状態表示

### サイドメニュー
- ハンバーガーボタン（☰）でオープン
- オーバーレイクリックで閉じる
- Esc キーで閉じる
- 5ページへのナビゲーション
- アクティブページのハイライト

### 未完了タスク一覧 (`#tasks`)
- 全未完了タスクを表形式で表示
- 表示項目: タスク名 / 進捗バー / 次のサブタスク / 着手日 / 締切日
- 行クリックでタスク設計画面へ遷移
- 右上の「新規」ボタンで新規タスク作成

### タスク設計画面 (`#design`)
- Notion風のインライン直接編集UI
- タスクタイトル（大見出しで編集）
- タスク基本情報（着手日・締切日）
- サブタスクのインライン表形式編集
  - No / チェックボックス / タイトル / 着手日 / 締切日 / リンク / 削除
- Enter キーで次のサブタスクを即追加
- チェックボックスでサブタスク完了/未完了切替
- 全サブタスク完了時に親タスクを自動完了

### URL機能
- サブタスクごとに複数URLを追加可能
- 表示名 + URL の設定
- チップUI表示 → クリックで新タブ起動
- チップのXボタンで削除

### サブタスク分割 (`#split`)
- ホーム画面の「サブタスクを分割」ボタンから遷移
- 分割前サブタスクを参考表示（編集不可）
- Notion風の表形式で複数のサブタスクを下書き入力
- 保存すると、元のサブタスクは削除され、同じ位置へ新しいサブタスク群が挿入される
- 着手日・締切日・URL・実行条件は分割前サブタスクから初期値としてコピーされる（編集可）

### 完了済みタスク (`#completed`)
- 全サブタスク完了時に自動で完了扱い
- 完了タスクの一覧表示（サブタスク詳細付き）
- ゴミ箱へ移動ボタン

### ゴミ箱 (`#trash`)
- タスク削除時はゴミ箱へ移動（ソフトデリート）
- 個別復元 / 個別完全削除
- 「全て削除」でゴミ箱を一括空にする

## 💾 データ構造

### Task（`onestep_tasks` に保存）

| フィールド | 型 | 説明 |
|---|---|---|
| id | string | UUID風のユニークID |
| title | string | タスクタイトル |
| startDate | string | 着手日（YYYY-MM-DD） |
| dueDate | string | 締切日（YYYY-MM-DD） |
| completed | boolean | 完了フラグ |
| deleted | boolean | ゴミ箱フラグ |
| createdAt | string | 作成日時（ISO） |
| updatedAt | string | 更新日時（ISO） |

### SubTask（`onestep_subtasks` に保存）

| フィールド | 型 | 説明 |
|---|---|---|
| id | string | UUID風のユニークID |
| taskId | string | 親タスクID |
| order | number | 内部の並び順（0始まり）。保存操作のたびに自動で整えられる |
| no | number | 表示用の番号（1始まり）。orderから自動採番、編集不可 |
| title | string | サブタスクタイトル |
| startDate | string | 着手日（YYYY-MM-DD） |
| dueDate | string | 締切日（YYYY-MM-DD） |
| completed | boolean | 完了フラグ |
| deleted | boolean | ゴミ箱フラグ |
| links | array | `[{ label, url }]` |
| contextValueIds | array | 実行条件（場所・状態など）候補IDの配列 |
| createdAt | string | 作成日時 |
| updatedAt | string | 更新日時 |

---

## 🏠 表示優先順位（ホーム画面）

1. 未完了サブタスクのみ対象
2. 締切日が近い順（昇順）
3. 締切が同一の場合は作成順（昇順）
4. 着手日前でも表示対象

---

## ⌨️ キーボードショートカット

| キー | 動作 |
|---|---|
| `Esc` | モーダルを閉じる / サイドバーを閉じる |
| `Enter`（サブタスク入力中） | 次のサブタスクを追加 |
| `Enter`（モーダル内） | フォームを保存 |
